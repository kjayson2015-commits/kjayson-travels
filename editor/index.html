Connect your GitHub

Your threads are saved straight into your site's GitHub repo, and the site rebuilds itself about a minute later. You only do this once per device.

  1. Open GitHub → New fine-grained token.
  2. Name it KJayson Travels editor. Under Repository access choose Only select repositories → kjayson-travels.
  3. Under Permissions → Repository → Contents choose Read and write. Generate the token and copy it.

It stays in this browser only. Never share it or post it anywhere.
